# Customer Service Request Analysis

## Project Overview

This project analyzes the NYC 311 Customer Service Requests dataset using Python. The goal is to clean the data, perform exploratory data analysis (EDA), visualize complaint patterns, calculate response times, and perform statistical analysis.

## Objectives

- Import and explore the dataset
- Handle missing values
- Clean invalid records
- Calculate request closing time
- Visualize complaint trends
- Analyze complaints across cities
- Perform Kruskal-Wallis H Test
- Present key insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Statistical Analysis
6. Observations and Conclusions

## Key Findings

- Missing values were handled successfully.
- Invalid date records were removed.
- Complaint response time was calculated in seconds.
- Complaint frequency varied across cities.
- Certain complaint types required significantly longer response times.
- Kruskal-Wallis H Test was performed to compare response times.
